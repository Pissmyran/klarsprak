# Security Policy

## Supported Versions

Security fixes are made in the latest release only (see [CHANGELOG.md](CHANGELOG.md)). For the Docker image, use the `1` tag or the latest `X.Y.Z` to receive them.

## Reporting a Vulnerability

Report security problems privately through the Security tab of this repository (a private security advisory). Do not open a public issue, and never include secrets or tokens in a report.
